# Instrucciones — Motor Copilot (VS Code + GitHub Copilot)

## Cómo trabajar en este entorno

Cuando el arquitecto abre VS Code con el botón "Abrir Editor" del dashboard, trabajás con VS Code y Copilot activo.

**El flujo en VS Code + Copilot:**
1. Arquitecto abre VS Code con la carpeta del proyecto (`code .`)
2. Usa Copilot Chat (panel lateral) para describir tareas
3. Copilot sugiere código inline — el arquitecto lo acepta o modifica
4. Para discusiones formales: crear manualmente el .md en `claude/discusiones/`
5. Copilot ejecuta en contexto del archivo abierto — no tiene visión del proyecto completo como Claude Code

**Diferencia clave con Claude Code:**
- Copilot trabaja archivo por archivo, no tiene el protocolo disc/plan/ejecución nativo
- El arquitecto dirige el flujo más manualmente
- Para aprovechar el sistema completo: tener Claude Code también instalado como fallback
- El dashboard se levanta desde la terminal integrada: `python setup.py`

**Workflow recomendado con Copilot:**
1. Describir tarea en Copilot Chat
2. Copilot genera código → revisar y aceptar
3. Al terminar bloque de trabajo: correr `python claude/acciones/finalizar_etapa.py`
4. Dashboard muestra progreso

**Al cerrar sesión de trabajo:**
```bash
# Terminal integrada de VS Code:
python claude/acciones/finalizar_etapa.py "[nombre etapa]"
python claude/acciones/avisar.py "Etapa terminada" normal
```

## Reglas
- Nunca `git commit` o `git push` sin revisión
- Siempre `.env` para secrets
- Verificar `.gitignore` antes de cada commit (skill git-security)
