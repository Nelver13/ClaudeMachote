# Instrucciones — Motor Cursor

## Cómo trabajar en este entorno

Cuando el arquitecto abre Cursor con el botón "Abrir Editor" del dashboard, trabajás con Cursor IDE y su agente IA integrado.

**El flujo en Cursor:**
1. Arquitecto abre Cursor con la carpeta del proyecto
2. Usa el chat de Cursor (Cmd/Ctrl+L) para describir tareas
3. Cursor Agent ejecuta el trabajo directamente en los archivos
4. Las discusiones y planes se crean en `claude/discusiones/` y `claude/planes/` igual que con Claude Code
5. Al terminar una etapa: correr `python claude/acciones/finalizar_etapa.py "[nombre]"` desde terminal

**Diferencia clave con Claude Code:**
- No hay hooks automáticos — el arquitecto corre los scripts manualmente desde la terminal de Cursor
- El dashboard igual se puede levantar: `python setup.py` o `python claude/acciones/iniciar_dashboard.py`
- Token tracking es estimado (Cursor no expone los mismos paths de tokens)

**Para abrir el dashboard desde Cursor:**
```bash
# En la terminal integrada de Cursor:
python setup.py
```

**Al cerrar sesión de trabajo:**
```bash
python claude/acciones/finalizar_etapa.py "[nombre etapa]"
python claude/acciones/avisar.py "Etapa terminada" normal
```

## Reglas
- Nunca `git commit` o `git push` sin revisión del arquitecto
- Siempre `.env` para secrets
- Discusiones en `claude/discusiones/creaciones/` o `soluciones/`
