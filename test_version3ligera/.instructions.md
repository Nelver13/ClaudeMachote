# Version3Ligera — Instrucciones para Motores AI

## 🎯 PROPÓSITO
Este proyecto usa **Version3Ligera**, un framework de desarrollo asistido por IA diseñado para **minimizar el gasto de tokens** mediante automatización inteligente.

## 📋 REGLAS PRINCIPALES

### ❌ NO HACER (gasta tokens innecesariamente)
- Analizar código/archivos que ya existen → usar herramientas de búsqueda
- Leer archivos completos sin necesidad → usar rangos específicos
- Repetir explicaciones ya documentadas → referenciar archivos existentes
- Preguntar por estructura del sistema → leer ROADMAP.md
- Recrear lógica que ya existe en scripts → ejecutar scripts directamente

### ✅ SÍ HACER (optimiza el uso)
- **Leer ROADMAP.md** completamente antes de cualquier acción
- **Usar scripts de automatización** en `claude/acciones/`
- **Consultar base de datos SQLite** para información histórica
- **Usar dashboard web** para métricas y estado
- **Ejecutar comandos** en lugar de escribir código manual

## 🛠️ HERRAMIENTAS DISPONIBLES

### Scripts Ejecutables (prioridad máxima)
```bash
python claude/acciones/init_db.py          # Inicializar base de datos
python claude/acciones/log_tokens.py       # Registrar tokens usados
python claude/acciones/motor_detect.py     # Detectar IDE/motor actual
python claude/acciones/finalizar_etapa.py  # Extraer métricas automáticamente
python claude/acciones/iniciar_dashboard.py # Iniciar interfaz web
```

### API Endpoints (desde dashboard)
- `GET /api/status` → Estado general
- `GET /api/tokens/etapas` → Costos por etapa
- `POST /api/etapas/crear` → Nueva etapa
- `POST /api/etapas/{id}/finalizar` → Cerrar etapa

## 🔄 FLUJO DE TRABAJO

1. **SIEMPRE** leer ROADMAP.md primero
2. **Crear discusión** → `discusiones/borrador/disc_[tema].md`
3. **Aprobar** → Mover a `discusiones/final/` con `Estado: Aprobado`
4. **Generar plan** → `planes/plan_[numero].md` con checklist
5. **Ejecutar** → Marcar `[x]` cada tarea completada
6. **Finalizar** → Ejecutar `finalizar_etapa.py` automáticamente

## 📊 ARCHIVOS DE REFERENCIA

- **ROADMAP.md** → Guía completa del sistema
- **claude/dashboard/app.py** → API del servidor web
- **claude/acciones/** → Scripts de automatización
- **claude/logs/tokens.json** → Historial de uso
- **claude/reports/reports.db** → Base de datos SQLite

## 🎯 OPTIMIZACIÓN

- **Tokens promedio por feature:** 500-2000
- **Tiempo setup:** 5 minutos
- **Auto-extracción:** Métricas calculadas automáticamente
- **Dashboard:** Monitoreo en tiempo real sin recargar
