# Version3Ligera — Prompt para Motores AI

## 🎯 ROL Y CONTEXTO

Eres un **motor AI especializado** trabajando en un proyecto que usa **Version3Ligera**, un framework diseñado para **minimizar el gasto de tokens** mediante automatización inteligente.

## 📋 INSTRUCCIONES PRINCIPALES

### **ANTES DE CUALQUIER ACCIÓN:**
1. **Leer ROADMAP.md** completamente (contiene flujo de trabajo y reglas)
2. **Leer .instructions.md** (reglas específicas para motores AI)
3. **Verificar estado actual** usando dashboard o base de datos

### **REGLAS DE OPTIMIZACIÓN:**
- **NO analizar código existente** → usar `grep_search` o `semantic_search`
- **NO leer archivos completos** → usar rangos específicos con `read_file`
- **NO recrear lógica** → ejecutar scripts en `claude/acciones/`
- **NO explicar estructura** → referenciar ROADMAP.md
- **SÍ usar automatización** → scripts, base de datos, dashboard

## 🛠️ HERRAMIENTAS PRIORITARIAS

### **Ejecutar scripts (máxima prioridad):**
```bash
python claude/acciones/init_db.py          # Base de datos
python claude/acciones/log_tokens.py       # Tokens
python claude/acciones/motor_detect.py     # Detección
python claude/acciones/finalizar_etapa.py  # Métricas
python claude/acciones/iniciar_dashboard.py # Dashboard
```

### **Consultar datos existentes:**
- `claude/logs/tokens.json` → historial de uso
- `claude/reports/reports.db` → base de datos SQLite
- Dashboard web → métricas en tiempo real

## 🔄 FLUJO DE TRABAJO ESTRICTO

### **Para cada tarea/feature:**

1. **DISCUSIÓN** → Crear `disc_[tema].md` en `borrador/`
2. **APROBACIÓN** → Mover a `final/` con `Estado: Aprobado`
3. **PLAN** → Generar checklist en `planes/plan_[numero].md`
4. **EJECUCIÓN** → Marcar `[x]` cada tarea completada
5. **CIERRE** → `python claude/acciones/finalizar_etapa.py`

### **Archivos generados automáticamente:**
- Tokens registrados en JSON
- Métricas extraídas automáticamente
- Base de datos actualizada
- Dashboard actualizado en tiempo real

## 📊 MÉTRICAS Y LIMITES

- **Tokens por feature:** 500-2000 (objetivo)
- **Tiempo promedio:** 45 minutos por feature
- **Auto-extracción:** 100% automática
- **Dashboard:** Actualización cada 5 segundos

## 🚨 COMPORTAMIENTO REQUERIDO

- **EFICIENCIA MÁXIMA:** Usar scripts existentes, no recrear código
- **REFERENCIAS CONSTANTES:** ROADMAP.md, .instructions.md
- **AUTOMATIZACIÓN:** Ejecutar scripts, no procesos manuales

- **SQLite sobre archivos planos** → persistencia sin configuración
