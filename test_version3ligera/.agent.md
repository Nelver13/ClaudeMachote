# Version3Ligera — Configuración de Agente AI

## 🤖 PERFIL DEL AGENTE

**Tipo:** Agente de desarrollo asistido por IA
**Especialización:** Framework Version3Ligera
**Objetivo:** Maximizar eficiencia, minimizar gasto de tokens

## 🎯 COMPORTAMIENTO REQUERIDO

### **Modo de Operación:**
- **Lectura inicial obligatoria:** ROADMAP.md, .instructions.md, .prompt.md
- **Ejecución prioritaria:** Scripts automatizados sobre código manual
- **Consulta de datos:** Base de datos y logs antes de análisis
- **Persistencia:** Registrar todas las acciones en SQLite/logs

### **Restricciones:**
- **NO analizar código existente** sin usar herramientas de búsqueda
- **NO leer archivos completos** sin rangos específicos
- **NO recrear lógica** que existe en scripts
- **NO explicar estructura** del sistema (referenciar docs)
- **NO gastar tokens** en tareas automatizables

## 🛠️ HERRAMIENTAS AUTORIZADAS

### **Scripts (prioridad máxima):**
- `claude/acciones/init_db.py` → Inicialización de base de datos
- `claude/acciones/log_tokens.py` → Registro de tokens
- `claude/acciones/motor_detect.py` → Detección de entorno
- `claude/acciones/finalizar_etapa.py` → Extracción automática
- `claude/acciones/iniciar_dashboard.py` → Interfaz web

### **API Endpoints:**
- `/api/status` → Estado del sistema
- `/api/tokens/*` → Información de costos
- `/api/etapas/*` → Gestión de etapas

### **Herramientas de búsqueda:**
- `grep_search` → Búsqueda de texto en código
- `semantic_search` → Búsqueda semántica
- `read_file` → Lectura con rangos específicos

## 🔄 PROTOCOLO DE EJECUCIÓN

### **Para cada tarea:**

1. **Verificar documentación** → Leer ROADMAP.md si es necesario
2. **Consultar estado** → Dashboard o base de datos
3. **Ejecutar script apropiado** → No recrear lógica
4. **Registrar acción** → En logs y base de datos
5. **Verificar resultado** → Usar dashboard para confirmación

### **Flujo de desarrollo:**
```
Discusión → Aprobación → Plan → Ejecución → Cierre Automático
    ↓          ↓          ↓       ↓            ↓
 borrador/  final/    plan_*.md  [x] tasks   finalizar_etapa.py
```

## 📊 MÉTRICAS DE EFICIENCIA

### **Objetivos:**
- **Tokens por feature:** < 2000
- **Tiempo de setup:** < 5 minutos
- **Tasa de automatización:** > 80%
- **Errores manuales:** 0

### **Monitoreo:**
- Dashboard web actualizado cada 5 segundos
- Logs JSON para historial completo
- Base de datos SQLite para métricas persistentes

## 🚨 PROTOCOLO DE ERROR

### **Si algo falla:**
1. **Verificar scripts existentes** → No recrear soluciones
2. **Consultar logs** → Historial de acciones previas
3. **Usar dashboard** → Estado visual del sistema
4. **Ejecutar diagnóstico** → Scripts especializados

### **No hacer:**
- Debug manual extenso
- Análisis de código sin herramientas
- Recrear funcionalidades existentes

## 🎯 OPTIMIZACIONES ESPECÍFICAS

### **Para minimizar tokens:**
- **Referencias constantes** a documentación existente
- **Ejecución de scripts** en lugar de código inline
- **Consulta de base de datos** antes de análisis
- **Uso de dashboard** para estado en tiempo real

### **Patrones eficientes:**
