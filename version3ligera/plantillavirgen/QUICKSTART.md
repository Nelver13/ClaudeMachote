# ⚡ **Inicio Rápido — 3 Minutos**

## 🚀 **Comandos Esenciales**

```bash
# 1. Copiar plantilla
cp -r plantillavirgen/ mi_proyecto/
cd mi_proyecto/

# 2. Instalar dependencias
pip install flask

# 3. Inicializar sistema
python claude/acciones/init_db.py
python claude/acciones/motor_detect.py

# 4. Iniciar dashboard
python claude/acciones/iniciar_dashboard.py
```

## ✅ **Verificación**

Abre `http://localhost:5000` en tu navegador.

**Si funciona:** ✅ Verde en todas las pestañas
**Si hay errores:** Revisa la consola del terminal

## 🎯 **Primer Uso**

1. **Crear discusión:** Botón "gen_discusión" en pestaña Comandos
2. **Ver progreso:** Pestaña Status se actualiza automáticamente
3. **Ejecutar tareas:** Botón "ejecutar_plan" cuando tengas planes
