# Contexto — Cursor IDE
> Instrucciones específicas para Cursor en version3ligera

Mismo flujo que Claude pero optimizado para Cursor IDE:

- **Detección**: Auto en cada inicio
- **Estructura**: `discusiones/borrador/` → `final/`
- **Planes**: `planes/plan_XXX.md`

El workflow es idéntico. Solo cambian los prompts optimizados para Cursor.

## Archivo de prompts

Ver `prompts.json` — contiene placeholders para:
- Contexto actual
- Último plan
- Borradores pendientes
- Feedback pendiente

Cursor carga eso automáticamente.
